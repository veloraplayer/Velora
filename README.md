**Velora** is a sleek, lightweight local music player for Windows built around clean aesthetics, smooth motion, and an immersive listening experience.

## 🌐 Multilingual UI

English, 한국어, 日本語, 简体中文, 繁體中文, Español, Français, Deutsch

## ⬇️ Download & Installation (Windows 64-bit)

Download the latest version from **[GitHub Releases](https://github.com/veloraplayer/Velora/releases/latest)**:

| Package | Description |
| :--- | :--- |
| **`Velora-Setup-x.x.x-win64.exe`** *(Recommended)* | Standard Windows installer. No admin rights required by default. Supports optional audio file association. |
| **`Velora-Portable-x.x.x-win64.zip`** | Portable edition — unzip and run anywhere. Settings and playlists are stored inside the local `data/` folder. |
| **`SHA256SUMS.txt`** | SHA-256 checksums to verify download integrity. |

> [!NOTE]
> **Windows SmartScreen Notice:** Because Velora is independently distributed without a paid code-signing certificate, Windows may display *"Windows protected your PC"* on first launch. Click **More info → Run anyway** to proceed. You can verify the file hash against `SHA256SUMS.txt`.

## ⌨️ Quick Tips & Shortcuts

| Action | Shortcut / Gesture |
| :--- | :--- |
| Play / Pause | `Space` |
| Enter / Exit Listening Mode | Double-click or drag up the player bar |
| Switch Visualizer (Listening Mode) | Left-click album art (Right-click for options) |
| Adjust Background Blur | Right-click empty background in Listening Mode |
| Fullscreen | `F11` / `Alt+Enter` |
| Zoom Album Grid / Track List | `Ctrl` + Mouse Wheel |
| Settings / Help & Shortcuts | `Ctrl+,` / `F1` |
